# マグロのようにスイスイ回る通院アプリ（モック）

近畿大学病院 通院支援アプリアイデアコンテスト2026 — チーム「地方キャンパスにも恵みを」の提出用モックです。
見た目は本戦で使った `demo.html` を引き継いでいます。そのうえで、**画面の裏で「いつ・何がきっかけで・どこに・何を送るか」** をイベントログとして見られるようにしました。

## 動かし方

```bash
npm install
npm run dev      # 開発（http://localhost:5173）
npm run build    # 提出用 → リポジトリ直下の index.html（1ファイル）を上書き。push すると GitHub Pages に反映
```

## キーボード操作（`?` で一覧表示）

| キー | 動作 |
|---|---|
| `1`〜`5` | 場面へジャンプ（来院前／移動中／院内／診察後／帰宅） |
| `→` / `←` | シナリオを1ステップ進める／戻す |
| `A` / `E` / `N` / `C` / `D` | 到着／採血完了／順番が進む／呼び出し／診察終了 |
| `X` | 出口へ移動（未完了の検査があれば帰宅防止アラート） |
| `P` | 診察券（アプリ内の QR）を表示 |
| `V` | AI の案内役を切り替え（テキスト → 2D → 3D。やさしい表示では 3D を使わない） |
| `G` / `O` / `K` | 位置情報・通信・カード登録 の ON/OFF（できないときの画面を確認） |
| `Y` / `M` | やさしい表示・音声 の ON/OFF |
| `F` | 提案資料（スライド 04・06・08・09）の項目から、その機能の場面へ飛ぶ（上部バーの「資料」でも開ける） |
| `B` | お知らせ（ベル）を開く。ここから端末の通知（ブラウザの通知機能）もオンにできる |
| `L` / `R` | イベントログの開閉／最初から |

スマホで開いたときは、上部バーの `‹ ›` と、画面内の「▶ デモ：」ボタンで同じ操作ができます。

## ファイル構成

- `index.html`（直下） … ビルド済みの提出用ファイル。GitHub Pages はこれを表示する（手で編集しない）
- `src/index.html` … 開発用の入口

- `src/sim/model.js` … 通院の流れ（状態と出来事）とシナリオ。外部連携はすべてここでログとして記録する
- `src/keys.js` … キー割り当て
- `src/screens/` … 各画面（ホーム・院内案内・院内マップ・受付・支払い・記録・AI・アカウント／家族連携・救急外来・駐車場・カフェ売店・お薬・領収書）
- `src/sim/map.js` … 院内マップ（模式図）の地点と経路探索。階・館は公式フロアマップに合わせ、形と通路は説明用
- `src/avatar/` … AI 案内役（2D／3D・口パク・読み上げ）
- `src/components/` … 通知・帰宅防止アラート・デバッグパネルなど

「（想定）」と書いた連携先（予約・受付システム、電子カルテ、決済など）は設計案です。実際の仕様は、病院・事業者と協議して決める部分です。
AI の応答は固定の文章です（オフラインでも確実に動かすため）。
